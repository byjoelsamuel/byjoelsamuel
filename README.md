### Homelab [🖥️]

Repurposed my old Lenovo IdeaPad into a self-hosted server — running Debian (XFCE) with Docker + Portainer managing:

- **Pi-hole** — network-wide DNS ad blocking (currently limited due to T-Mobile)
- **Nextcloud** — self-hosted cloud storage (replaced Google Drive)
- **Jellyfin** — self-hosted media server
- **Ollama + Open WebUI** — local LLM running fully offline
- **Homepage** — custom live dashboard for all services (CPU/RAM/disk/network stats + per-app status)
- **Tailscale** — secure remote access to everything from anywhere
- Hard Drive formatted and mounted for storage, backing Nextcloud + Jellyfin's media library
